## 1 软件概述

### 1.1 软件名称与版本

软件全称：一键出海AI多行业外贸出海平台，版本号：V1.0（以下简称"本平台"）。

### 1.2 开发目的与用途

本平台面向中国中小制造工厂与贸易商，提供一站式外贸出海服务。平台界面为中文（面向国内工厂用户），产出物为英文外贸官网与英文海外市场调研报告。平台通过AI Agent工作流驱动，帮助不具备外贸经验的工厂用户完成"市场调研 → 官网生成 → 域名上线 → 运营推广 → 询盘跟进 → 数据复盘"的完整出海闭环。

### 1.3 主要特点

（1）AI Agent工作流驱动：八个核心功能均以"拆解任务 → 调用模型/数据源 → 结构化产出"的智能体工作流方式实现。

（2）行业包可插拔架构：平台底座通用，泵阀、鞋服、教玩具、服装辅料、农产品等行业能力以可插拔行业包形式提供，支持用户自建自定义行业包。

（3）事实可追溯：市场调研报告采用来源分级（L1官方/法规至L4社区）、事实卡片、置信度标注与独立校验记录，保证AI产出可核查。

（4）本地化部署友好：平台为纯前端站点加轻量PHP/Python后端，可部署于普通云服务器。

### 1.4 名词术语

AI Agent：人工智能智能体，能够自动拆解任务、调用工具与模型并产出结构化结果的工作流单元。

行业包：针对特定行业的参数字段、资质选项、目标市场与关键词策略的插件化配置集合。

GEO（Generative Engine Optimization）：面向AI生成引擎的优化，检测ChatGPT、Perplexity、Gemini、Grok、Copilot、豆包等AI引擎是否引用用户网站。

询盘：海外买家通过网站表单发出的采购意向信息。

## 2 运行环境

### 2.1 硬件环境

服务器端（推荐配置）：CPU 2核及以上；内存 4GB及以上；硬盘 40GB及以上；具备公网IPv4地址。

客户端（推荐配置）：CPU 双核1.8GHz及以上；内存 4GB及以上；硬盘剩余空间 500MB及以上；分辨率1366×768及以上。

### 2.2 软件环境

服务器端操作系统：Linux（CentOS 7+/Ubuntu 18+）或 Windows Server 2016及以上。

Web服务：Nginx 1.18+ 或 Apache 2.4+。

后端脚本环境：PHP 7.4及以上（含cURL、OpenSSL扩展）；Python 3.8及以上（本地开发服务）。

客户端浏览器：Chrome 90+、Edge 90+、Firefox 88+或其他基于Chromium的现代浏览器。

### 2.3 网络环境

服务器与客户端均需接入互联网；访问大模型API、域名注册商接口、七牛云对象存储时需要HTTPS出网能力；推荐带宽不低于5Mbps。

## 3 软件体系结构

本平台采用"前端平台 + 后端接口 + 本地开发服务 + 上线执行工具"的四层轻量架构，全部代码均为自主编写，各部分说明如下。

### 3.1 前端平台

前端平台由三个文件组成一个完整站点：

（1）index.html：平台页面结构，包含主工作区与模型设置、新建行业包、生成中、全屏结果四个弹层；

（2）styles.css：平台界面样式，定义导航、卡片、表单、图表与响应式布局；

（3）app.js：核心业务逻辑，包括行业包定义与切换、市场分析工作流、网站生成引擎、工厂站模板、询盘与数据看板。

（4）sites目录：存放泵阀、箱包两个行业的演示站点，用于展示生成效果。

### 3.2 后端接口

后端接口由PHP实现，提供以下服务：

（1）认证服务：auth-login（登录）、auth-send-code（发送邮箱验证码）、auth-check（登录态校验）、auth-logout（退出登录）、_auth（会话公共库）；

（2）大模型服务：chat.php为大模型对话代理接口，统一管理模型调用；

（3）域名服务：domain-check.php调用域名注册商接口，实时检查域名可注册性；

（4）云存储服务：qiniu-token.php按七牛官方HMAC-SHA1签名算法生成上传凭证，qiniu-save.php与qiniu-status.php负责配置保存与状态查询；

（5）运维服务：health.php提供健康检查。

### 3.3 本地开发服务

07-本地开发目录下的server.py为Python实现的本地HTTP服务，承担静态资源分发与API转发，供开发者在本地环境完整调试平台功能。

### 3.4 上线执行工具

09-上线执行目录提供Node.js/Python自动化脚本集，覆盖DNS解析操作、站点创建、安全检查、发布部署与版本回滚等上线全流程操作。

### 3.5 数据流说明

用户在浏览器完成操作后，前端将请求提交至后端接口；后端按需调用大模型API、域名注册商接口或对象存储服务，并将结构化结果返回前端渲染。密钥类敏感信息仅存于服务端配置文件，浏览器侧不落地保存。

## 4 系统初始化与基础配置

### 4.1 打开平台

步骤1：在浏览器地址栏输入平台访问地址（本地开发时为 http://localhost:8080，线上为部署域名）。

步骤2：进入平台首页后，顶部导航展示八个核心功能入口，右上角提供"云存储"与"模型设置"按钮。

### 4.2 模型设置

步骤1：点击右上角"模型设置"按钮，弹出模型配置弹层。

步骤2：填写大模型服务商地址、API密钥与模型名称。

步骤3：点击"测试连接"，系统调用chat接口验证连通性，提示成功后保存。

说明：密钥仅保存在服务端配置文件，不会存储在浏览器中。

### 4.3 云存储配置

步骤1：点击右上角"云存储"按钮，弹出云存储配置弹层。

步骤2：填写七牛云的AccessKey、SecretKey与Bucket名称。

步骤3：点击"测试连接"，服务端按七牛官方签名算法（HMAC-SHA1）生成上传凭证并校验。

步骤4：测试通过后即可在网站生成流程中直接上传产品图片等文件。

### 4.4 用户注册与登录

功能说明：平台后端提供基于邮箱验证码的用户注册登录体系，保护平台功能不被未授权访问。

操作步骤：

步骤1：首次使用点击登录入口，输入邮箱地址，点击"发送验证码"。后端auth-send-code接口生成校验码并发送至该邮箱。

步骤2：输入收到的验证码与基本信息，完成注册并登录。

步骤3：系统签发登录凭证，后续请求经auth-check接口校验登录态；凭证失效时需重新登录。

步骤4：点击"退出登录"，后端auth-logout接口注销本次会话。

## 5 功能模块操作说明

本平台顶部导航共设八个核心功能入口，全部功能均以AI Agent工作流驱动：拆解任务 → 调用模型/数据源 → 结构化产出。以下按功能逐一说明操作方法。

### 5.0 功能总览

（2）出海网站生成：工厂信息 → 英文外贸官网；

### 5.1 市场营销分析（深度研究版）

功能说明：输入1至3张产品照片及可选补充信息，产出结构化海外市场调研报告。

操作步骤：

步骤1：在顶部导航点击"市场营销分析"，进入分析工作区。

步骤2：上传产品照片（1至3张），可选填产品补充信息。

步骤3：点击"开始分析"，系统按深度研究方法论执行：问题类型与时效界定 → 边界定义 → 来源分级检索（L1官方/法规至L4社区）→ 生成带来源、时效、置信度的事实卡片 → 构建本产品与市场对标的对比框架 → 形成推导链 → 场景验证 → 独立校验记录 → 常规分析。

步骤4：等待约40至70秒，报告生成完毕，顶部展示"结论速览"一行摘要。

输出结果：共12章的市场调研报告，含竞争力分析、八大市场五维打分与推荐排序、合规要点与进入建议；支持导出Word与PDF。

## 7 系统部署与运维说明

### 7.1 本地开发环境部署

步骤1：安装Python 3.8及以上版本，进入07-本地开发目录。

步骤2：执行命令 python server.py，启动本地HTTP服务，默认监听8080端口。

步骤3：浏览器访问 http://localhost:8080 即可打开平台进行调试；server.py承担静态资源分发与API转发。

### 7.2 生产环境部署

步骤1：将平台静态文件（index.html、styles.css、app.js及sites目录）上传至云服务器Nginx/Apache站点根目录。

步骤2：将06-后端接入的api目录部署至服务端PHP运行环境，复制auth.config.example.php与llm.config.example.php为正式配置文件，并填写七牛云密钥与大模型API密钥。

步骤3：配置Nginx将/api路径转发至PHP处理，并启用HTTPS证书。

步骤4：验证health.php返回正常后，平台即对外可用。

### 7.3 上线执行工具

09-上线执行目录提供一套自动化运维脚本：

（1）dns系列脚本：域名解析查询、添加与诊断；

（2）publish.js：将平台站点文件打包发布至目标服务器；

（3）run_sec_check系列脚本：发布后安全检查与清理；

（4）snip系列脚本：服务器配置片段的读取、写入与校验；

（5）rollback目录：每次发布自动留存上一版本快照，出现异常时可快速回滚。

### 7.4 安全机制

（1）大模型API密钥、七牛云密钥仅存放于服务端配置文件，不下发浏览器。

（2）上传凭证按七牛官方HMAC-SHA1签名算法在服务端生成。

（3）用户登录采用验证码校验与会话凭证机制，接口侧对未登录请求进行拦截。

（4）发布流程内置安全检查脚本，发布后自动扫描页面残留与敏感内容。

## 8 常见问题与注意事项

（1）模型测试连接失败：检查API密钥有效性、服务商地址拼写与服务器出网情况。

（2）云存储测试失败：核对AccessKey/SecretKey/Bucket三者是否匹配，确认七牛云空间已创建。

（3）域名检查结果异常：域名可注册性为实时数据，若接口繁忙请稍后重试。

（4）报告生成中断：多为模型网络超时，重新点击"开始分析"即可。

（5）内容合规：平台产出内容仅供外贸经营参考，涉及资质、认证与出口管制事项，请以官方主管部门要求为准。

（6）数据备份：定期在服务端备份网站生成文件与询盘数据。
